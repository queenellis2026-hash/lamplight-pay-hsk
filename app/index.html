2. Token

Test-token note — read this first. The deployed MockUSDC's mint is deployer-only: only the deploying wallet can mint it, so you cannot mint mUSDC yourself from this page. If you do not already hold mUSDC, use the custom token field below with any ERC-20 test token you do hold on HSK testnet (for example, a token you deployed yourself for testing). The escrow works with any ERC-20; it does not require mUSDC specifically. The Mint button below is included for the deployer only and will revert for everyone else.
